# homework-bot-vk

VK-бот, который следит за статусом проверки домашних работ в Яндекс Практикуме.

Раз в 10 минут бот обращается к API сервиса "Практикум Домашка". Когда статус работы меняется, бот присылает сообщение в VK: работа взята на ревью, принята или возвращена с замечаниями.

## Что умеет

- Проверяет статус домашних работ каждые 10 минут.
- Присылает в VK сообщение о новом статусе работы.
- Сообщает в VK о сбоях: API недоступен, пришёл неожиданный ответ или неизвестный статус. Если одна и та же ошибка повторяется, сообщение о ней приходит один раз, а все повторы пишутся только в лог.
- Ведёт лог в стандартный вывод: дата и время, уровень, описание события.
- Не запускается без обязательных переменных окружения: пишет в лог запись уровня `CRITICAL` и останавливается.

## Технологии

- Python 3.12+
- requests — запросы к API Практикума
- vk_api — отправка сообщений в VK
- python-dotenv — чтение переменных окружения из `.env`
- pydantic — проверка ответа API

## Переменные окружения

Создайте в корне проекта файл `.env`:

```
PRACTICUM_TOKEN=<OAuth-токен API Практикум Домашки>
VK_TOKEN=<токен VK с правом отправки сообщений>
VK_USER_ID=<ваш id в VK, кому бот пишет>
```

Файл `.env` внесён в `.gitignore` и в репозиторий не попадает.

## Установка и запуск

```
git clone git@github.com:AndrewKozyrev/homework-bot-vk-new.git
cd homework-bot-vk-new
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
python homework.py
```

Бот работает, пока его не остановят (Ctrl+C).

## Структура

- `homework.py` — логика бота: проверка переменных, запрос к API, проверка ответа, разбор статуса, отправка в VK, основной цикл `main()`
- `utils.py` — модели ответа API (pydantic)
- `exceptions.py` — собственные исключения
- `tests/` — автотесты
